# Shoko — 書庫

観た映画・ドラマ・アニメ・同人を記録しておくための、個人用アプリ。

記録も感想も表紙画像も、**すべて自分の端末の中**に保存される。サーバもアカウントも無い。

---

## できること

- TMDB / AniList から作品を検索して登録（表紙・あらすじ付き）
- 手入力での登録（同人誌など、公開データベースに無いもの）
- 状態の管理：これから見る / 見ている途中 / 見た / 一時中断 / 見るのをやめた
- 話数の枠を API から取り込んで、**1話ごとに記録**を残す
- 作品ごとの**総評**（書き直せる）と 5 段階評価
- R18 の表紙をぼかす伏せ字表示
- 「掘り起こし」— n 年前の同じ日に書いた記録を拾い上げる
- JSON での書き出し / 読み込み

---

## 置き方

### A. GitHub Pages（無料・リポジトリは公開になる）

1. GitHub で新しいリポジトリを作る（例：`shoko`）
2. この一式をそのまま push する（またはブラウザから全ファイルをアップロード）
3. Settings → Pages → Source を `Deploy from a branch` にし、ブランチ `main` / フォルダ `/ (root)` を選ぶ
4. 数十秒後 `https://ユーザー名.github.io/shoko/` で開ける

無料プランでは、Pages は公開リポジトリでしか使えない。

### B. Cloudflare Pages（無料・リポジトリを非公開にできる）

1. リポジトリを private のまま用意する
2. Cloudflare の Workers & Pages → Create → Pages → Connect to Git
3. 対象リポジトリを選ぶ。ビルド設定は**すべて空のまま**（ビルド不要）
4. `https://xxxx.pages.dev/` が発行される

どちらの場合も、**公開されるのはアプリの入れ物だけ**で、記録したデータは一切含まれない。

## 使いはじめ

### 1. TMDB のキーを入れる

映画・ドラマの検索に必要（アニメは AniList を使うので、キー無しでも動く）。

1. https://www.themoviedb.org/settings/api でキーを取得する
2. アプリ右上の ⚙ を開き、「TMDB API キー」に貼って保存

キーは端末の中だけに保存される。**このリポジトリのコードには一切含まれていない**ので、公開しても漏れない。

うまく繋がらないときは、⚙ の「接続を確認する」で TMDB と AniList それぞれの状態を見られる。

### 2. ホーム画面に追加する（Android 推奨）

Chrome でサイトを開き、メニュー →「アプリをインストール」または「ホーム画面に追加」。

こうするとアドレスバーの無い状態で起動し、他のアプリの**共有メニューに「書庫」が出る**ようになる。気になった作品を共有すれば、そのタイトルで検索した状態で立ち上がる。

---

## バックアップ（ここが一番大事）

データは端末の中にしか無いので、**機種変更・アプリ削除・ストレージの初期化で消える**。

⚙ →「JSON で書き出す」で全件を書き出せる。手入力した表紙画像も含まれる。書き出したファイルは Google ドライブなどに置いておくのが安全。

30 日書き出していないと、起動時に上部で知らせる。

新しい端末では ⚙ →「JSON から読み込む」で戻せる。

## ファイル構成

```
index.html              アプリ本体（これ 1 枚で全部動く）
manifest.webmanifest    ホーム画面への追加と共有メニューの設定
sw.js                   オフラインで開くための Service Worker
icons/                  アイコン
```

ビルド不要。`index.html` をブラウザで直接開いても動く。

## データの持ち方

| 置き場所 | 中身 |
|---|---|
| IndexedDB `shoko-db` | 作品・記録・総評・話数・設定・手入力の表紙画像 |
| 外部 | 何も送信しない |

書き出した JSON にはバージョン番号が入るので、将来この形式が変わっても古いファイルを判別して読める。
